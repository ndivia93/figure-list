깃헙 이미지 주소 변환
깃헙 사진 주소(github.com/…/blob/…)를 사진 전용 원본 주소(raw.githubusercontent.com)로 바꿉니다. 깃헙 사진이 한꺼번에 안 뜨는 현상을 줄여줍니다. 깃헙 주소만 바뀌고 다른 사이트 주소는 그대로 둡니다.
깃헙 사진 → 업로드 사진으로 옮기기
깃헙 사진을 받아서 내 구글 드라이브의 업로드 사진으로 바꿉니다. 옮긴 뒤에는 깃헙 접속 제한과 상관없이 빠르게 뜹니다. 썸네일 위치·확대 설정은 그대로 유지되고, 원래 주소는 기록으로 남겨둡니다. 구글 동기화 로그인이 필요합니다.
단일쿠폰 부호 일괄 통일
모든 항목의 단일쿠폰을 한쪽 부호로 맞춥니다. 실제 낸 금액(총비용)은 그대로 두고 결제금액 칸(마지막 결제 항목)을 쿠폰만큼 자동으로 맞춥니다. 원화 쿠폰은 원화 결제금액, 외화 쿠폰은 같은 통화의 현지가를 조정합니다.
− : 할인전 금액 − 쿠폰 = 할인후 금액  /  + : 할인후 금액 + 쿠폰 = 할인전 금액
