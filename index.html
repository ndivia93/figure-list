구글 로그인 · 드라이브 저장 프로토타입

피규어리스트 외부 연동 검증용 · 데이터/사진을 내 구글 드라이브 appData에 저장하고 불러옵니다.

① 설정 최초 1회

아래에 구글 클라우드 OAuth 클라이언트 ID를 넣어야 로그인이 됩니다.
· Google Cloud Console → 프로젝트 생성 → API 및 서비스 → 사용자 인증 정보 → OAuth 클라이언트 ID(웹) 만들기
· 승인된 자바스크립트 원본에 이 페이지의 https 주소(예: https://이름.github.io) 등록
· API 및 서비스 → 라이브러리에서 Google Drive API 사용 설정
· OAuth 동의화면을 "외부/테스트"로 두고 본인 이메일을 테스트 사용자로 추가 (검증 없이 사용)
· 요청 권한(scope): drive.appdata
입력한 ID는 이 브라우저(localStorage)에만 저장됩니다.
